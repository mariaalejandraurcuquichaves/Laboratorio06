# Laboratorio 06: Arquitectura Java: de la ejecución del programa a la memoria

## Descripción
En este laboratorio se estudió la arquitectura de Java (JDK, JRE, JVM), la compilación, el funcionamiento de la memoria (Stack vs Heap), el paso de parámetros por valor y el manejo de referencias con objetos.

## Estructura de Archivos
- `src/com/laboratorio06/Mascota.java`: Clase base de modelo.
- `src/com/laboratorio06/MemoryDemo.java`: Demostración de Stack, Heap y paso por valor.
- `src/com/laboratorio06/MemoryChallenge.java`: Reto integrador y manejo de NullPointerException.
